# BetterMillidaLauncher
Hello, its a fork of original Millida launcher without an account stealing and better.

## Instructions
### How to install
Open releases and download last version (Release version, not pre-release (Maybe unstable)). Put the .exe launcher to a folder (If you put to desktop and launch you get new files - data, instances, runtimes, millida_things, server, server_instances, settings, web). And launch the launcher.
